# Yet another online chess board
## By Cheze

Instead of using nicer looking, better functioning online chess sites like chess.com or lichess.org, I decided to make my own crappy version! Comes with local multiplayer and a very rudimentary bot, plus a small opening library.

Opening names are detected from the bundled [`data/codes.json`](./data/codes.json) FEN database from [chess-opening-info](https://github.com/porridgewithraisins/chess-opening-info). Its source dataset, [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings), is dedicated to the public domain under [CC0 1.0](https://github.com/lichess-org/chess-openings/blob/master/COPYING.txt).
